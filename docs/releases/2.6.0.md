# 2.6.0

An outline, to be put into the owner's words. 2.2 gave the map an Assistant,
with a model behind it or without, and keeps its own enhancements on its own
page; this is the other half of what was planned, moved on twice — once to make
room for Product Areas in [2.3.0](2.3.0.md), and again for people and access in
[2.4.0](2.4.0.md) and sandboxes in [2.5.0](2.5.0.md): the map reached by an
agent from outside. One rule holds throughout: **nothing changes the map
without a contributor's click.** An outside agent produces the same cards into
the same review that a connected model or a pasted reply does.

## The map over MCP

- stdio first: a `domain-map-mcp` bin that runs beside Claude Desktop, Claude Code or Copilot on the owner's machine. It reads an exported map file, or the API with a token. Nothing new is exposed by the server.
- Tools, all read-only but the last: `get_brief` (the map as a brief, with or without owners), `list_skills`, `get_prompt` (a skill and a subject in, the whole prompt out), `check_reply` (the same checks the Assistant runs, so an agent can fix its own reply), `submit_suggestions`.
- `submit_suggestions` does not change the map. It queues a review for a contributor in the `suggestions` table — the one [2.2.0](2.2.0.md) plans for a review kept on the server, or a migration here if that has not landed — holding the reply, who or what sent it, which version it was written against, and what became of each card. The Assistant lists the reviews waiting, and opens one as the cards it already knows how to show.
- Tokens: a contributor mints one in the app, scoped to read, or to read and submit. An agent cannot do the Entra sign-in dance, so this comes before anything over HTTP.
- HTTP after: `/mcp` on the server, behind a token, for the agents that live in the cloud and cannot run a bin.
- Open until this starts: hand-rolled JSON-RPC, keeping `pg` the only dependency, or the official MCP SDK as a second one. stdio for five tools is small enough to write; the HTTP transport is the part worth revisiting.
